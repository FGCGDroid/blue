# 攻击面图谱

`blue_risk_graph` 把资产、CVE 和未关闭发现放在同一张图里，用来排序“先查哪个资产”。

## 节点

```text
asset:资产
cve:CVE
finding:发现
```

## 边

```text
asset -> cve      潜在暴露（按名称/服务/tag 匹配，版本未验证）
asset -> finding  已有发现
```

## 风险分

```text
资产关键级别
+ 未关闭发现严重度
+ 匹配 CVE 严重度
= 0–100 排序分
```

它只是排序分，不是 CVSS，也不是“已确认漏洞”。

## 控制台

「图谱」页签展示：

- 对外/内部资产
- 风险条
- 每个资产关联的 CVE
- 每个 CVE 影响的资产数

## 边界

- 没有版本区间匹配，不能判定资产一定受影响。
- 没有网络拓扑，不能还原真实攻击路径。
- 匹配依据是资产名称/服务/tag，适合做排查起点，不适合做结论。
