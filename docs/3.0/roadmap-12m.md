# 3.0 一年节奏（2026-12 ~ 2027-12）

> 制定：2026-11-17  
> 背景：M0–M3.5 已经提前完成，但继续按“一晚一个里程碑”冲，会把验证和打磨压没。  
> 结论：从今天起切到月度小步，按一年排，不追进度，不缩测试。

## 总目标

```text
2027-08  3.0.0 发布（内核 + 73 工具，不含新控制台）
2027-12  3.1.0-rc（12 页签新控制台）
2028-01  3.1.0 发布
```

只算 3.0.0，从 2026-11 到 2027-08 正好 9 个月；加上 3.1.0 是 14 个月。  
用户口径“按 1 年搞”：3.0.0 在一年内，3.1.0 留一个季度缓冲。

## 当前基线

```text
M0 契约          完成
M1 骨架          完成
M2 数据层        完成（8 个 repo + 迁移回滚）
M3 路径阻断      完成（40 条向量 + 独立网关）
M3.5 响应/外锚   完成（manual/mock + file/https sink）

v3：107 个 JS
测试：9 个 v3 脚本
2.0：66 个工具，冻结
```

## 节奏

```text
每周          1–2 次工作会话，每次 2–4 小时
每月          一个主目标，最多两个工具组
每月最后一周  回归、文档、演示、复盘
不安排        通宵冲刺、跨月大爆炸、连续大提交
```

单次提交原则：

```text
优先 ≤ 300 行
超过 500 行必须拆
一个提交只做一件事
没有测试不合并
```

## 每个工具组的 DoD

```text
名称/参数/输出 schema 与 2.0 一致（新增 7 个按新契约）
有契约测试
有角色白名单测试
错误走 { ok:false, error }
tools 不写 SQL
tools 不 import ../lib
tools 不 import infra
文档更新工具数
```

## 每月质量门

```bash
npm.cmd run check:v3
npm.cmd run test:v3
node scripts/parity.mjs --engine=2.0
node scripts/validate.mjs
node scripts/test-tools.mjs
```

任何一门红：

```text
下个月只做加固，不加新功能
```

## 停止规则

出现以下任一情况，暂停新功能：

```text
路径阻断出现绕过
审批链被绕过
网关把应阻断请求转发到上游
响应执行器未经审批写 applied
外锚私钥/凭据出现在日志
2.0 回归失败
```

## 范围纪律

```text
3.0.0 只做 73 个工具 + 内核 + 影子双跑
3.1.0 只做 12 页签控制台
3.2+ 才做 RBAC、加密、回溯、多主机
```

不因为“顺手”加工具、加页签、加自动执行。

## 和现有里程碑的关系

```text
M0–M3.5  已完成，不再重开
M4       拆成 2027-01 ~ 2027-06 六个月
M4.5     2027-07
3.0.0    2027-08
M5       2027-09 ~ 2027-12

```

接入 `cordis.patch.yml`、写 npm `files`、切换默认版本，仍然只在 3.0.0 发布前做一次。

## 每次会话的固定动作

```text
开始：读 roadmap，确认本月目标
过程：只改本月范围；发现范围外问题记 backlog，不顺手做
结束：跑测试，更新文档，写一句“下次从哪继续”
```

不追求一晚推完。慢就是快。
