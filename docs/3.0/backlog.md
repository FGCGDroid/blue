> 状态：立项登记，未开工

## 3.0 必须做

### K. 跨越门（2.0 做不到）

| ID | 条目 | 验收 |
| --- | --- | --- |
| K1 | 真阻断 | 先判定后读 body；40 条向量全绿；canary 上游命中 0 |
| K2 | 策略可测试 | 策略版本化；validate / test / diff / reload；错误策略拒绝加载 |
| K3 | 受控响应执行 | dry-run 无副作用；无审批不能执行；执行后验证；失败可回滚 |
| K4 | 运营可见 | /metrics、/healthz；每规则命中、上游错误、策略版本可查 |
| K5 | 证据外锚 | 锚点可推 file / HTTPS webhook；外部锚可验证；失败不阻塞主流程 |

### A. 路径阻断内核

| ID | 条目 | 验收 |
| --- | --- | --- |
| A0 | 独立部署边界 | 网关独立进程、独立端口（默认 8787）；端口占用拒绝启动；不嵌入 DSH |
| A1 | 请求路径规范化 | 百分号解码一次；拒绝二次编码、点段、编码分隔符、反斜杠；折叠 `//`；Unicode NFC；拒绝超长 UTF-8 |
| A2 | 保护前缀策略 | 保护路径默认拒绝；允许列表可配置；大小写策略明确 |
| A3 | 先判定后读 body | 网关顺序固定为 normalize → policy → block/allow → 才读 body |
| A4 | 绕过头拒绝 | 拒绝 `X-Original-URL`、`X-Rewrite-URL`、`X-Forwarded-Prefix`、`X-Forwarded-Uri` |
| A5 | fail-closed | 解码失败、策略非法、配置错误一律阻断；策略缺失用内置最小策略 |
| A6 | canary 验证 | 保护路径的 canary 上游 `hit_count = 0` |
| A7 | 对抗向量 | 至少 40 条：编码、双编码、分号、反斜杠、绝对 URI、空路径、大小写、Unicode |
| A8 | 决策日志 | 每次阻断/放行记录规则 ID、规范化路径、原因，不记录敏感头 |

| ID | 条目 | 验收 |
| --- | --- | --- |

| B5 | 依赖检查脚本 | domain import infra/tools 时 CI 失败 |
| B6 | 端口接口 | TaskRepo、AuditLog、Clock、IdGen 显式定义 |

## 优先级规则

```text
1. 路径阻断 > 工具迁移 > 数据层 > 控制台
2. 正确性 > 性能 > 代码好看
3. 能测试 > 能演示 > 能写文档
4. 任何新需求先问：3.0 不做会不会导致防守失效？
   会 → 进 3.0
   不会 → 进 3.1/3.2
```
